# ✈️ Passport Template Clone

Veb proqramlaşdırma təlimimin **ikinci ayında** hazırladığım səyahət və turizm saytı şablonu. Bu layihə HTML5 və CSS3 istifadə edərək mürəkkəb kart strukturları, responsive düzen və vizual bölmələr qurmaq bacarıqlarımı təkmilləşdirmək üçün hazırlanıb.

## 🚀 Özəlliklər

- **Hero & Navigation Bar:** Loqo, keçid linkləri, dropdown menyu və fərdi arxa fon şəkil bölməsi.
- **Xidmət və Destinasiya Kartları:** Şəkillər və mətnlərlə bəzədilmiş dinamik görünüşlü layout.
- **Testimonials & FAQ:** Müştəri rəyləri və tez-tez verilən suallar üçün xüsusi dizayn olunmuş bloklar.
- **Xalis HTML & CSS:** Heç bir xarici JS karkası (framework) istifadə edilmədən, təmiz kodla yazılıb.

## 🛠️ İstifadə Olunan Texnologiyalar

- **HTML5**
- **CSS3**
- **Font Awesome** (İkonlar üçün)
